# 🏢 AI Real Estate Property Video Generator

An automated AI tool that converts property listing details and images into promotional videos with voiceover narration and customized visual themes.

## 🚀 Features
- **Web UI & CLI:** Built using Streamlit and Command-Line Interface.
- **AI Audio Narration:** Automated voiceover synthesis using `gTTS` with custom speed controls.
- **Multi-Format Export:** Supports 9:16 (Reels/Shorts), 16:9 (YouTube), and 1:1 (Social Feed) aspect ratios.
- **Custom Visual Branding:** Multiple color themes (Luxury Dark, Clean Minimal, Sunset).
